# Base Glossary

## Layer 2
A scaling solution that processes transactions outside the Ethereum mainnet while relying on Ethereum for security.

## OP Stack
An open-source framework used to build Ethereum Layer 2 networks.

## Sequencer
A component responsible for ordering and processing Layer 2 transactions.

## Bridge
A mechanism for transferring assets between Ethereum and Base.
## Rollup

A Layer 2 scaling approach that processes transactions off the Ethereum mainnet while relying on Ethereum for security and final settlement.

## Smart Contract

A self-executing program deployed on the blockchain that automatically performs predefined actions when conditions are met.
## Common Infrastructure Terms

### RPC
An RPC endpoint allows applications and developers to communicate with the Base network.

### Wallet
A wallet manages an account and allows users to approve transactions and interact with applications.

### Block Explorer
A block explorer provides a way to inspect transactions, blocks, addresses, contracts, and onchain activity.

### Smart Contract
A smart contract is code deployed onchain that can execute predefined logic when interacted with.
