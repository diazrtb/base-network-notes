# Cross-Chain Activity

## Overview

Cross-chain infrastructure allows users and applications to move assets and interact across different blockchain networks.

## Common Use Cases

- Moving assets between networks
- Cross-chain applications
- Liquidity transfers
- Multi-network user experiences

## Considerations

When using cross-chain infrastructure, users should verify supported networks, assets, fees, and transaction status.

## Notes

Cross-chain systems can improve interoperability while introducing additional technical and security considerations.
