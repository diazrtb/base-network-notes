# Onchain Data

## Overview

Onchain data provides a transparent record of activity on the Base network.

## Examples

- Transactions
- Block information
- Token transfers
- Contract events
- Wallet activity

## Why It Matters

Developers can use onchain data to monitor applications, analyze activity, and build data-driven tools.

## Notes

When analyzing blockchain data, always consider the source, timestamp, and network before drawing conclusions.
## Reading Onchain Activity

When reviewing blockchain activity, useful fields include:

- Transaction hash
- Block number
- Sender and receiver
- Token amount
- Transaction status
- Timestamp

These details can help developers and users understand what happened onchain.
## Data Verification

When analyzing onchain data, it is useful to verify information across multiple sources.

Useful checks include:

- Confirming the transaction hash
- Checking the block number
- Comparing timestamps
- Verifying contract addresses
- Reviewing transaction status

Accurate data verification helps prevent mistakes when analyzing blockchain activity.
