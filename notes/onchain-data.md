# Onchain Data

## Overview

Onchain data provides a transparent record of activity on the Base network.

## Examples

- Transactions
- Block information
- Token transfers
- Contract events
- Wallet activity

## Why It Matters

Developers can use onchain data to monitor applications, analyze activity, and build data-driven tools.

## Notes

When analyzing blockchain data, always consider the source, timestamp, and network before drawing conclusions.
