# Using a Block Explorer

## Overview

A block explorer helps users inspect blockchain activity on the Base network.

## Block Explorers for Base

- Base Mainnet: [basescan.org](https://basescan.org)
- Base Sepolia (testnet): [sepolia.basescan.org](https://sepolia.basescan.org) or [sepolia-explorer.base.org](https://sepolia-explorer.base.org)
Blockscout explorers are also available for both networks. Make sure the explorer matches the network you used, since a mainnet transaction will not appear on a testnet explorer.
## What You Can Search

- Wallet addresses
- Transaction hashes
- Block numbers
- Smart contract addresses

## Common Uses

- Verify transaction status
- Review token transfers
- Inspect contract activity
- Check block confirmations

## Notes

Block explorers improve transparency by making onchain activity easy to inspect.
## Reading Transaction Details

When viewing a transaction, you can typically find:

- Transaction status
- Block number and block confirmations
- Timestamp
- Sender and receiver addresses
- Transaction value
- Gas used
- Transaction fee
- Contract events and logs

Understanding these fields makes it easier to troubleshoot and verify onchain activity. Reviewing them can also help identify failed transactions and understand what happened onchain.
