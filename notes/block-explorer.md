# Using a Block Explorer

## Overview

A block explorer helps users inspect blockchain activity on the Base network.

## What You Can Search

- Wallet addresses
- Transaction hashes
- Block numbers
- Smart contract addresses

## Common Uses

- Verify transaction status
- Review token transfers
- Inspect contract activity
- Check block confirmations

## Notes

Block explorers improve transparency by making onchain activity easy to inspect.
## Reading Transaction Details

When viewing a transaction, you can typically find:

- Transaction status
- Block number
- Gas used
- Transaction fee
- Sender and receiver addresses
- Timestamp

Understanding these fields makes it easier to troubleshoot and verify onchain activity.
## Transaction Review

A block explorer can be useful when checking the details of a transaction.

When reviewing a transaction, look at:

- Transaction status
- Sender and recipient addresses
- Transaction value
- Gas information
- Block confirmation
- Contract events and logs

Reviewing these details can help identify failed transactions and understand what happened onchain.
