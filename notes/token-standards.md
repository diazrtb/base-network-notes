# Token Standards

## Overview

Token standards define common rules for creating and interacting with tokens on EVM-compatible networks.

## Common Standards

- ERC-20 for fungible tokens
- ERC-721 for NFTs
- ERC-1155 for multi-token applications

## Why Standards Matter

Using established standards improves compatibility between wallets, applications, marketplaces, and smart contracts.

## Notes

Developers should choose a token standard based on the requirements of their application.
## Choosing a Token Standard

The right standard depends on the type of application.

- ERC-20 works well for interchangeable assets.
- ERC-721 is useful when each token is unique.
- ERC-1155 can support multiple token types within one contract.

## Compatibility

Standardized token interfaces make it easier for wallets and applications to interact with tokens across the ecosystem.
