# Bridging Assets to Base

## Overview

Bridging allows users to move supported assets between Ethereum and the Base network.

## General Process

1. Connect a compatible wallet.
2. Select the source and destination networks.
3. Choose the asset and amount.
4. Confirm the transaction.
5. Wait for the transfer to complete.

## Notes

Always verify that you are using a trusted bridge and review transaction details before confirming.
