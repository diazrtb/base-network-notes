# Bridging Assets to Base

## Overview

Bridging allows users to move supported assets between Ethereum and the Base network.

## General Process

1. Connect a compatible wallet.
2. Select the source and destination networks.
3. Choose the asset and amount.
4. Confirm the transaction.
5. Wait for the transfer to complete.

## Notes

Always verify that you are using a trusted bridge and review transaction details before confirming.

## Deposits and Withdrawals

Moving assets from Ethereum to Base (deposits) is typically fast.

Standard withdrawals from Base back to Ethereum must wait for a 7-day challenge period before they can be finalized. Regular Base transactions are not affected by this wait.

Some bridge providers offer faster withdrawals, but they usually do not shorten the underlying standard withdrawal challenge period.

## Common Issues

Users may occasionally experience delays when bridging assets.

Possible reasons include:

- Network congestion
- Wallet connection problems
- Transaction confirmation delays
- Temporary bridge maintenance

## Recommendation

If a transfer takes longer than expected, check the transaction status before attempting another transfer.
