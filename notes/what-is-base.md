# What is Base?

Base is an Ethereum Layer 2 network designed to provide low transaction fees and fast confirmations.

## Key Features

- Built on the OP Stack
- Ethereum-compatible
- Lower fees compared to Ethereum mainnet
- Supported by Coinbase

## Purpose

Base aims to make onchain applications more accessible to developers and users.
