# Smart Contracts

## Overview

Smart contracts are programs deployed on a blockchain that execute predefined logic when their conditions are met.

## Common Uses

- Token transfers
- DeFi applications
- NFT collections
- Onchain marketplaces
- Automated transactions

## Development

Smart contracts on Base can be developed using familiar Ethereum tools and programming languages.

## Notes

Always test and review smart contracts carefully before deploying them to a production network.
