# Development Tools

## Common Tools

Developers building on Base often use familiar Ethereum tools.

- Hardhat
- Foundry
- Remix IDE
- MetaMask
- Block Explorers

## Benefits

These tools simplify contract development, testing, and deployment while maintaining compatibility with Ethereum.
## Getting Started

A typical development workflow includes:

1. Configure a local development environment.
2. Connect to the Base test network.
3. Deploy and test smart contracts.
4. Verify contract behavior before production deployment.

## Notes

Using a test environment helps identify issues before interacting with the live network.
