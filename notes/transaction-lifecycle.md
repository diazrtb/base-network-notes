# Transaction Lifecycle

A transaction on Base generally follows several steps from creation to confirmation.

## Basic Flow

1. A user creates a transaction.
2. The wallet asks the user to approve it.
3. The transaction is submitted to the network.
4. The network processes the transaction.
5. The transaction is included in a block.
6. The result can be reviewed through onchain data.

Understanding this flow makes it easier to troubleshoot transactions and understand how applications interact with the network.
